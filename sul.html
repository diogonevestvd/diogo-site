Sul

A planning system for direction, not noise.

An exploratory digital planning concept focused on information hierarchy, progressive guidance and calmer decision-making. It tests how structure, interface language and next-step clarity work together.

Type
Personal planning product
Focus
Goals, structure, direction, interface clarity
Status
Concept / in progress

01 / Logic

The product starts with one question: how can planning feel directional rather than overwhelming?

The answer is a system that reveals depth progressively. The user should see the next useful step before seeing the entire life plan.

02 / Structure

Progressive disclosure as a product philosophy.

Less text on first contact. More context only when the user asks for it. This makes the interface easier for new users without sacrificing depth.

GoalsMilestonesTasksReflectionProgress

03 / Language fit

Planning interfaces are also language systems.

Labels, instructions, empty states and hierarchy have to tell the user what matters next without creating more noise. Sul adds context for how short interface language interacts with structure and progressive disclosure.

What this demonstrates

Sul demonstrates information hierarchy, interface clarity and progressive disclosure, useful product context for evaluating how language fits constrained user flows.
