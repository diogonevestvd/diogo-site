QA de Localización PT-PT

De output simulado de MT/IA a portugués europeo listo para producto.

Creé esta muestra ficticia para demostrar cómo evalúo y localizo texto de interfaz para portugués europeo. El ejercicio parte de cinco strings en inglés y de una versión portuguesa deliberadamente imperfecta, simulando problemas frecuentes de MT/IA: interferencia PT-BR, calcos, errores de sentido, tono mecánico y formato regional inadecuado.

01 / Brief

Una prueba pequeña, estructurada como un flujo real de QA.

El escenario simula una aplicación SaaS internacional que prepara un flujo de onboarding para Portugal. El objetivo no es mostrar una traducción larga, sino hacer visible el juicio lingüístico: qué está mal, por qué importa y cómo corregirlo sin perder la función del texto de interfaz.

03 / Método

La revisión no termina cuando la gramática es técnicamente correcta.

1

Contextualizar

Definir locale, público, producto, intención y restricciones de espacio.

2

Evaluar

Comparar origen y output en precisión, fluidez, terminología y adecuación regional.

3

Localizar

Reescribir en un PT-PT natural manteniendo la función de cada string de interfaz.

4

Verificar

Hacer una segunda revisión de consistencia, puntuación, números, moneda y terminología.

04 / Entrega

El cliente recibe texto limpio y un registro breve de lo que se ha corregido.

En este tipo de trabajo entregaría copy listo para implementar y un informe QA breve con los problemas relevantes. El informe hace auditables las decisiones y ayuda a equipos de producto o localización a detectar patrones de error recurrentes.
