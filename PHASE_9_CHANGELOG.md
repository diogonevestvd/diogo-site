# Phase 9 Changelog

## Goal
Prepare the site for production: technical SEO, social sharing, responsive polish, accessibility, performance and final visual consistency.

## Changes
- Kept English as the default language at the site root, with Portuguese at `/pt/` and Spanish at `/es/`.
- Corrected stale structured-data URLs that still referenced the former `/en/` location.
- Refined page titles and descriptions around European Portuguese, localization QA, MT post-editing and AI language evaluation.
- Added index/follow directives to public pages and `noindex,follow` to the unfinished Notes pages.
- Removed Notes from the XML sitemap while keeping the URLs available for future use.
- Added a 1200 x 630 social sharing image and Open Graph/Twitter metadata to indexable pages.
- Added favicon and Apple touch icon assets.
- Added `og:locale` and alternate locale metadata for EN, PT-PT and ES.
- Added WebSite, Person and WebPage structured data to each language homepage.
- Added a custom 404 page.
- Optimized the homepage portrait to WebP and added explicit image dimensions and loading hints.
- Improved mobile-menu accessibility with focus management, keyboard trapping, Escape handling and focus restoration.
- Added balanced headline wrapping, safer overflow handling and small responsive refinements.
- Reworked the large dark Language feature on the homepage into a lighter paper-aligned two-panel composition. The burgundy language panel remains, but the content side now uses the site paper palette and the PT-PT mark is less dominant.
- Preserved the existing visual identity rather than introducing a new aesthetic system.
- Added `lastmod` values to canonical sitemap entries.
- No em dash character is used in public HTML, CSS, JavaScript or this changelog.
