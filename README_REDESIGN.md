# Diogo Neves - redesigned static site

This version rebuilds the website as a lightweight luxury paper portfolio.

## Key changes
- Morly is now the flagship project.
- Heavy animation libraries were removed.
- No GSAP, ScrollTrigger, Lenis, cursor orb, magnetic hover, or mouse-tracking card effects.
- Navigation is simplified to Projetos / Sobre / Notas / Contacto.
- Legacy URLs redirect to the new structure.
- Includes canonical metadata, Open Graph basics, robots.txt, sitemap.xml, and JSON-LD.

## Public links
- No public social profile links for now; direct contact is via email.
- GitHub and CV are intentionally not linked yet.

## Deployment
Upload the contents of this folder to the root of the hosting environment.
